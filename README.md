# EVENTRA – Event Planning Website

EVENTRA is a modern, responsive website for an event planning company, designed to showcase services, event galleries, creative team members, and client experiences.

## Features
- Responsive design using Tailwind CSS.
- Modern and elegant user interface.
- Hero, About, Services, and Portfolio sections.
- Interactive event galleries.
- Team and Testimonials sections.
- FAQ section.
- Contact form with JavaScript interaction.
- Smooth animations and hover effects.

## Technologies Used
- HTML5
- Tailwind CSS
- CSS3
- JavaScript
